# Product Requirements Document (PRD)

## 1. Product overview
This portfolio is a personal website for Harnish Prajapati, designed to showcase skills, selected projects, and contact information in a polished and modern format. The site should communicate professionalism, creativity, and technical ability while remaining simple to maintain.

## 2. Target audience
- Recruiters and hiring managers
- Potential clients and collaborators
- Friends, peers, and professional network contacts

## 3. Product goals
- Present a clear professional identity
- Highlight technical skills and design ability
- Showcase selected work effectively
- Create a strong first impression for visitors
- Make it easy to contact the owner

## 4. Core user flows
1. Visitor lands on the homepage and quickly understands who the person is.
2. Visitor scans the skills and project highlights.
3. Visitor clicks a CTA or contact link to reach out.
4. Visitor explores the site on desktop or mobile.

## 5. Functional requirements
- Homepage with hero section, about, skills, projects, and contact
- Clean navigation between sections
- Project cards with summary content
- Contact CTA with email or social link
- Responsive design for mobile, tablet, and desktop
- Dark theme by default
- Fast-loading static pages

## 6. Non-functional requirements
- Built with Next.js for performance and maintainability
- Use Tailwind CSS styling
- Ensure accessible text contrast and legible typography
- Maintain clean file structure and reusable components
- Keep the site easy to update with new projects or content

## 7. MVP scope
- Home page
- Portfolio section
- About and skills section
- Contact CTA
- Project detail path (optional next phase)

## 8. Future enhancements
- Individual project pages with richer case studies
- Blog or writing section
- Resume download button
- Social media links
- Theme toggle
- Contact form integration

## 9. Success metrics
- Visitor understands the portfolio within a few seconds
- High-quality visual impression across first screen
- Clear path to contact or collaboration
- Good mobile usability and page speed
