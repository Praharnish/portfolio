# Architecture

## 1. Project type
This is a personal portfolio site built with Next.js App Router and Tailwind CSS.

## 2. Tech stack
- Next.js 16
- React 19
- TypeScript
- Tailwind CSS
- ESLint

## 3. Structure
```text
portfolio/
├── app/
│   ├── globals.css
│   ├── layout.tsx
│   └── page.tsx
├── public/
├── README.md
├── package.json
├── tsconfig.json
├── next.config.ts
├── eslint.config.mjs
└── postcss.config.mjs
```

## 4. App architecture
- `app/layout.tsx` handles the root layout and metadata
- `app/page.tsx` defines the main landing page sections
- `app/globals.css` contains global styles and dark theme tokens
- `public/` can hold assets such as profile images or icons

## 5. Styling approach
- Tailwind utilities for layout, spacing, and component styling
- Global CSS for background gradients, smooth scrolling, and selection styling
- Dark visual theme with accent colors for contrast and personality

## 6. Rendering model
The site is statically generated by default for a fast portfolio experience. The page is simple, server-rendered, and lightweight.

## 7. Scalability considerations
- Add reusable data objects or content arrays for projects and skills
- Move repeated sections into components as the site grows
- Add route-based project detail pages later if a case-study section is introduced

## 8. Future architecture improvements
- `components/` directory for reusable UI blocks
- `data/` directory for structured portfolio content
- `lib/` directory for helper functions or formatting logic
- Optional CMS or markdown-driven content system
