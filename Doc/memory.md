# Project Context

## Portfolio context
This project is a personal portfolio website for Harnish Prajapati. It is being built as a dark-themed, premium single-page portfolio with sections for introduction, skills, selected projects, and contact.

## Stack
- Next.js
- React
- TypeScript
- Tailwind CSS

## Current goal
Create a clean and professional portfolio starter that can later be customized with real content, projects, and personal branding.

## Key decisions
- Dark mode is the default visual direction
- Use a minimal premium aesthetic rather than overly busy layouts
- Favor strong typography and large section spacing
- Keep content configurable through arrays to simplify updates

## Important notes
- Homepage is the current focus
- Content is intentionally reusable and easy to replace
- The project is designed to scale later into a more complete portfolio system
